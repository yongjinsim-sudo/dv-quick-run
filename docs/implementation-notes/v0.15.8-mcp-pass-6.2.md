# DV Quick Run v0.15.8 — MCP Capability Pass 6.2

## Runtime Strategy, Ranked-Anchor Probing, and Managed Readiness

Pass 6.2 closes the gaps exposed by Bupa dogfooding of Pass 6.1.

### Behaviour

- RuntimeRelationship evidence now satisfies both table and record runtime strategy steps.
- Record investigations use `record-investigation-v2`: scope, metadata, relationship context, runtime relationship evidence, readiness, and explicit Mini RCA review.
- Existing `record-investigation-v1` state is upgraded deterministically on load.
- Without an explicit target, Runtime Relationship probes at most three ranked relationship-context anchors in order and stops on the first observed target rows or budget exhaustion.
- With an explicit target, exactly that target is probed.
- The persisted evidence remains one normalized bounded runtime artifact; raw traversal responses are not persisted.
- Recommendations refer to the Runtime Relationship Evidence capability, not standalone OData.
- `dvqr_assess_investigation_readiness` accepts a persisted `investigationId` directly. Record and table investigations receive a stored `dvqr-managed-investigation-readiness-v1` result; canonical Timeline and Cross-Environment request contracts remain available only through their supported profiles.

### Evidence boundaries

Managed readiness is advisory and separate from canonical Timeline/Cross-Environment readiness. It does not certify causality, root cause, complete business-process execution, completeness, or remediation authority.
