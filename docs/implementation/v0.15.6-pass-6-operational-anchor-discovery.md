# DV Quick Run v0.15.6 — Implementation Pass 6

## Operational Anchor Discovery

This pass adds a source-first investigation stage before target-driven relationship discovery.

The new `dvqr_discover_operational_anchors` MCP tool explores a bounded relationship neighbourhood around a source table and separates:

- likely business workflow anchors;
- supporting anchors;
- downstream work-item evidence;
- platform or administrative infrastructure.

Ranking is structural first. Relationship centrality, inbound/outbound bridge shape, source proximity, ownership and one-hop work-item connectivity carry the main score. Names and descriptions contribute supporting evidence only.

The result remains metadata-bounded. It does not claim that records exist, that an anchor is causally responsible for work, or that the highest-ranked anchor is the organisation's authoritative business process. Runtime probing remains a separate investigation stage.
